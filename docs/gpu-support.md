# GPU Hardware

The supported GPU hardware is:

1. NVIDIA CUDA (v1, now)
2. AMD's ROCm (v3, future)
    - ROCm might only be supported on **vllm** (aka, not **llama.cpp**)
    - more research is needed
3. Intel XPU (v3, future)
    - more research is needed
4. Apple Silicon / METAL (v3, future)
    - Apple Silicon may be only supported on **llama.cpp** (aka, not **vllm**)
    - more research is needed
